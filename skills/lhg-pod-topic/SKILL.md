# lhg-pod-topic：播客选题与定位

> 目标：让每一期节目在开口录制前，就已经赢了一半。
> 核心纪律：**选题不过"三问过滤器"，不许写大纲；大纲没有钩子，不许开录。**

## 1. 何时使用

- 开新节目：先定"定位三件套"（第 3.1 节），再谈单期
- 策划单期：用"三问过滤器"验主题（第 3.2 节）
- 主题太大/太散：用"角度发散"切成可讲的一期（第 3.3 节）
- 写录制大纲：按第 3.4 节结构输出
- 访谈节目：按第 3.5 节设计嘉宾问题

## 2. 输入 / 输出

**输入**：一句话想法（如"聊聊副业"）、可选嘉宾信息、可选目标听众描述。

**输出**：
- 新节目：节目名（3 选 1）+ slogan + 听众画像卡
- 单期：过过滤器的选题一句话 + 3 个备选角度（用户拍板）+ 录制大纲（含开场钩子、话题块、结尾）

## 3. 分步方法论

### 3.1 定位三件套（开新节目用）

1. **节目名**：给出 3 个候选，要求——3 秒能记住、发音无歧义、说出名字能猜到大概讲什么。避开生僻字和谐音梗（口播时说不清）。
2. **slogan**：一句话，格式"给的电台/节目"。如"给上班族的副业试错电台"。
3. **听众画像卡**：
- 他是谁（年龄/职业/城市 tier 可写大概）
- 他为什么听（通勤？做家务？睡前？）
- 他听完能带走什么（一句话）
- 他还听什么节目（对标 2 个，用于差异化）

命名检查清单：去目标平台搜重名；全拼/缩写无不良联想；节目名 + slogan 连起来读一遍顺口。

### 3.2 选题三问过滤器（单期必过）

每个选题必须能回答：

1. **听众是谁？**——不能是"所有人"。说出具体的一类人，如"工作 3 年想搞副业但没头绪的运营"。
2. **这期解决什么问题？**——一句话，如"帮他判断第一个副业选什么方向"。说不清=选题太大，回去切。
3. **你的信息差是什么？**——你凭什么讲这个？亲身经历、独家数据、深度访谈，三者至少占一个。都没有=这期别做，做了也是复述。

三问都答得上 → 过；任何一问含糊 → 回 3.3 切角度，或直接换题。

### 3.3 角度发散：把大主题切成一期

大主题（如"副业"）天然讲不完。用"一切三"法：

- 按**人群**切：上班族副业 / 宝妈副业 / 大学生副业
- 按**阶段**切：选方向 / 冷启动 / 放大收入
- 按**反常识**切：副业最大的坑不是没时间（反常识角度最容易出爆款）

每次输出 3 个备选角度 + 每个角度的一句话卖点，用户拍板一个再往下走。

### 3.4 录制大纲结构

```markdown
# EPxx 大纲：标题

## 开场钩子（30 秒，必须写逐字稿）
- 用故事/数据/反常识开场，不许用"大家好我是xx，今天我们来聊聊xx"平铺直叙。
- 好钩子公式：具体场景 + 冲突/悬念。如"去年我花 3 个月做的副业，上线 7 天就死了——死在第一个月我就该发现的问题上。"

## 话题块（3~4 个，每块 8~12 分钟）
### 块一：关键词
- 核心问题（一句话）
- 追问方向（2~3 个，防自己讲空）
- 案例/数据（至少 1 个具体的，标来源；不确定的标[待确认]）

## 结尾（2 分钟）
- 一句话总结：这期最想让听众带走的
- 行动建议：具体到"今晚就能做的一件事"
- 下期预告：一句话钩子
```

大纲纪律：话题块之间写一句过渡语（剪辑时不断裂）；总时长按"话题块×10 分钟+开场结尾 5 分钟"估算，超 60 分钟就砍一块。

### 3.5 访谈节目的嘉宾问题设计

1. **嘉宾介绍织入法**：不念简历。用"他做过一件什么事"开场，如"王强去年用 2000 块启动了一个副业，现在月入 2 万——先问问他第一笔钱怎么赚的"。
2. **问题排序**：热身（经历）→ 深水（方法论）→ provocative（争议观点）→ 收尾（建议）。由浅入深，嘉宾进入状态后再问难的。
3. **准备 2 个救场问题**：冷场时用，如"如果回到三年前，你会给自己什么建议""最近让你最兴奋的一件事"。
4. **禁区清单**：提前和嘉宾对好不聊的话题，写进大纲备注。

### 3.6 系列化策划：10 期节目弧线

单期做顺之后，用"弧线"把听众留下来：

1. **定弧线主题**：10 期讲透一件事，如"副业从 0 到 1 的 10 步"。每期独立可听，连起来是体系。
2. **排播节奏**：第 1 期讲"为什么"（动机），第 2–8 期讲"怎么做"（方法），第 9 期讲"坑"（避雷），第 10 期做"听众问答+复盘"（互动）。
3. **钩子预埋**：每期结尾预告下期时，抛一个"下期才回答的问题"，如"选方向容易，难的是冷启动没人理——下期讲 0 粉丝怎么做第一波流量"。
4. **复用选题库**：建一个选题池文档，每来一个灵感就扔进去，标注"三问过滤器"得分；策划时从池子里捞，不用每次从零想。

选题池条目模板：

```markdown
- 选题：xxx
- 听众/问题/信息差（三问一句话版）
- 备选角度：a / b / c
- 状态：待策划 / 已排期 EPxx / 已发布
- 发布后数据：完播率 xx%，评论关键词
```

## 4. 反模式

- ❌ "这期聊聊副业"直接开录——没有过滤器的大主题=车祸现场
- ❌ 开场 2 分钟还在自我介绍——听众 30 秒决定去留
- ❌ 大纲只有标题没有追问方向——录到一半没话讲，只能靠"嗯""对"水时长
- ❌ 访谈问题按简历顺序问——像查户口，不像聊天
- ❌ 案例无来源、数据随口说——播客没有弹幕纠错，错了就是错了

## 4.5 常见问题

**Q：选题会上觉得都很好，拍板不下来怎么办？**
A：用"信息差"做决胜项——三个角度里，哪个你最有独家经历/数据，选哪个。都没信息差的，说明这期不该你做。

**Q：访谈嘉宾临时放鸽子？**
A：大纲里常备 1 期"单人兜底选题"（你最熟的话题），嘉宾缺席直接切换，不用临时抱佛脚。

**Q：一期想讲 5 个话题？**
A：砍到 3 个。听众记住 1 个就值回票价，5 个等于没讲。多的进选题池。

## 5. 自检与反馈

执行完本 skill，自检三问：

1. 选题三问都能一句话答上吗？→ 答不上回炉。
2. 开场钩子读出来，30 秒内有悬念/冲突吗？→ 没有重写。
3. 大纲里有没有 `[待确认]`？→ 有就先确认，不许带着问号录。

标准冒烟用例：用"给新手父母的睡眠科普"走一遍 3.2–3.4，检查输出是否包含过滤器三问答案、3 个备选角度、带逐字稿钩子的大纲。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-podcast/issues，正文写清"输入 → 错误输出 → 期望输出"。
