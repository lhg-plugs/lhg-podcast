# lhg-pod-edit：播客剪辑方法论

> 目标：听众听不出剪辑痕迹，只觉得"这人说话真利索"。
> 核心纪律：**剪辑是减法；保留呼吸感，只删伤害体验的部分。**

## 1. 何时使用

- 录完 raw 音频：先输出剪辑工单（第 3.1 节），再动手剪
- 不知道"什么该删"：按"三刀流"（第 3.2 节）过一遍
- 切章节：按第 3.3 节标点
- 导出前：按第 3.4 节做响度与格式

## 2. 输入 / 输出

**输入**：raw 音频（或转录稿+时间戳）、目标时长。

**输出**：剪辑工单（待删清单+章节切分点）→ 成片音频（-16 LUFS，mp3/m4a）→ 剪辑记录（删了什么、为什么）。

## 3. 分步方法论

### 3.1 先出工单，再动手（5 分钟通听）

通听一遍（2 倍速也行），记下：

```markdown
## 剪辑工单 EPxx
- [ ] 02:14–02:31 大段静音（喝水）
- [ ] 07:02 口头禅"然后"三连
- [ ] 15:40–16:05 跑题（和主题无关的闲聊）
- [ ] 28:33 喷麦，修或重说
- [ ] 章节切分点：00:00 / 08:20 / 16:40 / 25:00 / 33:20 / 40:50
- [ ] 目标时长：45 分钟内（当前 52 分钟，需砍 7 分钟）
```

工单纪律：不确定删不删的标 `[待定]`，剪完回听再定；不许边剪边找，效率差三倍。

### 3.2 三刀流：静音 / 口头禅 / 废话

**第一刀：静音与气口**
- 超过 1.5 秒的静音：压到 0.5 秒（留白是节奏，全删就喘不上气）。
- "嗯""啊"语气词：句首的保留（自然），句中连续 3 个以上的删到 1 个。

**第二刀：口头禅**
- 录制时记下的 top3，逐个搜、逐个听、逐个删。
- 删口头禅最容易出"跳剪感"：前后各留 0.1 秒淡入淡出，或用房间 tone 补。

**第三刀：废话与跑题**
- "就是说""换句话说"后面的重复解释，二选一。
- 跑题超过 1 分钟且与主题无关：整段拿掉（可单独存成番外）。
- 同一个观点说了两遍：留讲得好的那遍。

三刀之后回听一遍：只听"顺不顺"，不纠结细节。顺=过。

### 3.3 章节切分

- 切分点=话题切换处，和 shownotes 时间戳一一对应（见 lhg-pod-distribute）。
- 切分粒度：8–12 分钟一块；少于 5 分钟的块合并，听众切来切去会烦。
- 片头片尾：片头音乐/口播 15 秒内，片尾"下期预告+订阅引导"30 秒内。

### 3.4 响度与导出（技术规格）

1. **响度目标**：立体声播客 **-16 LUFS**（单声道 -19 LUFS）。这是 Apple Podcasts / Spotify 通行的播客人声标准，平台会对偏离的节目做归一化——偏离太多会被压得忽大忽小。
2. **流程**：降噪（轻度）→ EQ（切 80Hz 以下低频）→ 压缩（人声 3:1 起步）→ 响度归一到 -16 LUFS → 限幅防削波。
3. **导出**：mp3 128k–192k（通用）或 m4a；采样率 44100Hz；文件名小写英文连字符（如 `ep08.mp3`）。
4. **质检**：导出后听开头 2 分钟+随机跳 3 处，确认无爆音、无音量跳变、无漏剪的"嗯——"。

### 3.5 剪辑记录（给未来的自己）

```markdown
## 剪辑记录 EPxx
- 删除：静音 12 处 / 口头禅 23 处 / 跑题段 1 段（15:40–16:05，存番外）
- 时长：52:10 → 43:25
- 遗留：28:33 喷麦轻微，修后可接受
```

### 3.6 音乐与多轨：少即是多

1. **片头/片尾音乐**：15 秒内，音量比人声低 12dB 以上（ducking：人声进来时音乐自动压低）。
2. **转场音效**：话题块之间可用 1 秒短音效，不用每块都用——用多了像电台广告。
3. **背景音乐**：谈话类播客建议**不要**全程铺 BGM。人声是主角，BGM 会和人声抢频段，听久了累。
4. **版权**：只用自制/已购版权/平台免费曲库的音乐。"网上下载的热歌"不算来源，发布等于埋雷。

### 3.7 导出前最终检查单

- [ ] 响度表确认 -16 LUFS（立体声）/ -19 LUFS（单声道）
- [ ] 峰值不超过 -1dBTP（防削波）
- [ ] 开头 2 分钟 + 随机 3 处抽听：无爆音、无漏剪
- [ ] 文件名：小写英文连字符（如 `ep08.mp3`）
- [ ] 导出参数：mp3 128k–192k / 44100Hz；或 m4a
- [ ] 剪辑记录已写（删了什么、时长变化、遗留问题）

## 4. 反模式

- ❌ 逐字精修每一句——播客不是朗诵，过度剪辑=机器人味
- ❌ 降噪拉满——人声变"水下音"，不如重录那段
- ❌ 响度凭感觉调——导出 -16 LUFS 是硬标准，不是审美
- ❌ 剪完不回听直接发——90% 的漏剪都是这一步省掉的
- ❌ 把"嗯"全删光——适度的语气词是"人味"，全删像 AI 配音

## 4.5 常见问题

**Q：剪辑一期 40 分钟节目要多久？**
A：新手 3–4 小时，熟练后 1.5 小时内。超过 4 小时说明在"精修每一句"——回到三刀流，只做减法。

**Q：口头禅实在太多，删完像机器人？**
A：留 30%。口头禅是"人味"的一部分，全删反而假。删的标准：连续出现/盖住关键词的删，偶发的留。

**Q：-16 LUFS 怎么测？**
A：用响度表插件/软件的"响度归一化"功能直接设目标值，不要凭耳朵拧音量。不同软件叫法不同，认准"LUFS/Loudness Normalize"。

**Q：嘉宾说错了一个数据，整段重录还是硬剪？**
A：能让嘉宾补录一句就补录；补录不了就在 shownotes 里勘误。别用剪辑"拼"出一句没说过的话——这是红线。

**Q：要不要加字幕/文字版？**
A：shownotes 就是文字版。逐字稿适合SEO但工作量大，折中方案：shownotes 时间戳+金句摘录，文字版等节目跑顺再说。

**Q：剪辑软件崩溃丢进度？**
A：每完成一刀就存盘+导出小样。长节目分段工程文件，别把 2 小时全堆在一个工程里。

## 5. 自检与反馈

剪辑完成自检：

1. 工单上的项都处理了吗？`[待定]`的有结论了吗？
2. 回听一遍顺不顺？→ 有跳剪感就回退那一刀。
3. 响度表确认 -16 LUFS？导出文件名合规？
4. 时长达标了吗？→ 超了就再砍一块，别"就这样吧"。

标准冒烟用例：给一段 5 分钟带口头禅/静音的转录稿（带时间戳），检查工单是否列出三类待删项、章节切分点、目标响度。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-podcast/issues，正文写清"输入 → 错误输出 → 期望输出"。
