# /lhg-podcast:podcast —— 一期节目全流程

用户输入在 `$ARGUMENTS` 中：`[主题/嘉宾] [--guest 嘉宾名]`。只给主题则做单人节目，加 `--guest` 则按访谈节目编排。

## 流程（按顺序加载 4 个 skill 全程指导）

### 1. 选题（加载 lhg-pod-topic）
- 用"三问过滤器"验主题：听众是谁、一句话能说清这期解决什么问题、你有没有信息差可讲。
- 输出：一句话选题 + 目标听众 + 3 个备选角度（用户拍板一个）。

### 2. 大纲（加载 lhg-pod-topic 第 3 节）
- 输出录制大纲：开场钩子（30 秒）→ 3~4 个话题块（每块核心问题+追问方向+案例/数据）→ 结尾（一句话总结+行动建议+下期预告）。
- 访谈节目：嘉宾介绍自然织入、不念简历；准备 2 个"救场问题"防冷场。

### 3. 录制指引（加载 lhg-pod-record）
- 输出设备/环境/话术清单：麦克风摆位、房间处理、语速与停顿、嘉宾提醒事项（别敲桌子、手机静音）。
- 远程录制必须双轨本地录音备份（云端录制只当备份的备份）。

### 4. 剪辑清单（加载 lhg-pod-edit）
- 输出剪辑工单：静音段落、口头禅清单、章节切分点、响度目标 -16 LUFS。
- 不做"美化式剪辑"：保留呼吸感，只删伤害体验的部分。

### 5. shownotes 与交付（加载 lhg-pod-distribute）
- 生成 shownotes.md（时间戳章节从 00:00 开始、单集时长、工具/书籍外链）。
- 交付物清单：音频文件、封面（1400–3000 正方形）、chapters.json、feed.xml 的 item 字段。

### 6. 自查
跑 `/lhg-podcast:audit`，blocker 清零才算做完。

## 硬规则
- 选题没过"三问过滤器"不许直接写大纲——先回头换题。
- 录制前没有"嘉宾提醒事项"就开录 → 不许（返工成本最高的一步）。
- shownotes 没有时间戳章节不许说"交付完成"。
